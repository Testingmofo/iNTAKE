## iNTAKE v0.2.6 Beta

### Cyberdeck window
- Adds the transparent, angular iNTEL-inspired window silhouette with clipped corners and a raised control tab.
- Keeps the window interior opaque while the area outside the silhouette stays transparent.
- Preserves the existing drag, resize, minimize, maximize/restore, and close controls.

### Included
- Current iNTAKE JavaFX application and browser extension 1.3.5.
- Self-contained Windows installer and portable package with the private Java runtime and bundled media tools.

This is an unsigned beta release. Verify downloads against `SHA256SUMS.txt`.
